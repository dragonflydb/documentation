# CLI

The [redis-cli](https://docs.redis.com/latest/rs/references/cli-utilities/redis-cli/) can also be used with Dragonfly, supporting nearly all of the same commands.

If you have questions or would like assistance, please join our [Slack community](https://join.slack.com/t/dragonflycommunityhq/shared_invite/zt-4ftpylx50-SQZ0g0CD2lJMvi0EsqPNbQ) or [get in touch with our team](https://www.dragonflydb.io/early-access).
